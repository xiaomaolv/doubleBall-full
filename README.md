## 项目简介
基于原生 JavaScript 实现的单页面双色球模拟选号工具，无需后端，直接浏览器打开即可运行。
内置3种选号模式：
1. **普通随机模式**：随机生成 6红+1蓝 标准一注号码，红球自动升序排序
2. **反向排除模式**：手动勾选想要排除的红球/蓝球，在剩余号码池内随机生成号码
3. **抽取27红15蓝，取剩余一注**：随机抽走27个红球、15个蓝球，剩下的6红+1蓝组成一注，同时展示被抽走的全部号码

## 运行方法
1. 新建文本文档，把上面完整网页代码复制进去
2. 将文件另存为 `doubleBall-full.html`，编码选择 `UTF-8`
3. 双击该 html 文件，会自动用浏览器打开（Chrome、Edge、Firefox均可）
> 不需要安装任何软件、不需要服务，纯本地离线运行，数据不会上传网络。

## 使用操作指南
### 模式1：普通随机模式
- 单选框选择【普通随机模式】
- 点击【生成号码】，直接随机得到一组6+1双色球号码

### 模式2：反向排除模式
- 单选框切换【反向排除模式】，下方会出现全部号码面板
- 点击号码：变色代表**排除该号码**，再次点击取消排除
- 点击【生成号码】，仅在未排除号码池中随机选号
> 限制：不能排除过多号码，否则剩余号码不足会弹窗报错

### 模式3：抽取27红15蓝，取剩余一注
- 点击紫色按钮【【快速】抽取27红15蓝取剩余注】
- 自动执行：随机选出27红、15蓝；剩下6红+1蓝作为最终一注
- 页面下方额外展示本次被抽走的27个红球、15个蓝球清单

### 重置按钮
点击【重置】：清空选号结果、清空所有已勾选排除号码，恢复初始状态

## 核心源码函数
`generateDoubleBall(redBallNum, blueBallNum, excludeRed=[], excludeBlue=[])`
> 原始核心函数，支持自定义抽取红球、蓝球数量，支持传入排除号码列表，返回排序后的红球数组、蓝球数组。

## 特性
- 原生 HTML + CSS + JS，无第三方依赖
- 响应式布局，电脑浏览器使用体验最佳
